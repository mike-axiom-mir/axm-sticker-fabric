# Sticker fabric collaboration

Read current main and open PRs before work. One branch/PR lane per chat; keep
related repairs together. Preserve unrelated work and exact source provenance.

Internal gates are Truth, Agency/non-domination, Continuity, and Wisdom before
speed. Ground acceptance in actual evidence; status or access does not confer
canon authority. Human and machine callers have the same explicit authoring
controls. No automatic promotion of generated/practice output into user state.

UC must remain standalone. This repo is optional for UC; don't introduce a
required service or runtime checkout. Preserve portable version pins, original
editable sources and inspectable contracts. Never replace rich source with a
preview. Geometry/structural checks do not prove rendered/game quality.

Run installed package tests and all applicable checks at the actual PR head
before merge. Keep limits explicit; do not silently truncate large assemblies.
